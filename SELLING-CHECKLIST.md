# Selling Checklist

Use this checklist to turn the website into a real product-selling store.

## Before selling

- brand name is set
- homepage looks good
- shop page is ready
- category page is ready
- contact page is ready
- FAQ is ready

## For each product

- product title
- price
- short description
- product image
- product file ready
- product added to website catalog
- product route and cart flow checked

## Before publishing

- test homepage
- test product links
- test contact form behavior
- test mobile layout
- export final version

## Publish

- choose Netlify or Vercel
- upload the site
- choose a free subdomain
- test live website

## After publishing

- post the website link on Pinterest
- post on Instagram
- share one freebie for email growth
