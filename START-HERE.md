# Start Here

This project already includes a real website for your brand:

- `index.html` -> homepage
- `shop.html` -> shop page
- `category-wedding.html` -> category page
- `bundles.html` -> bundle page
- `free-resources.html` -> free download page
- `about.html` -> about page
- `faq.html` -> FAQ page
- `contact.html` -> contact page
- `login.html` -> account page
- `dashboard.html` -> dashboard page

You do **not** need to build the website from scratch anymore.

## Your goal

Use this website as your storefront, then connect products and publish it online.

## Step-by-step plan

### Step 1: Open the website

Open:

- `index.html`

This is your homepage.

## Step 2: Edit the design in the browser

Use the `AI Helper` button inside the website.

Example prompts:

- `make it lighter`
- `accent blue`
- `button shape rounded`
- `set hero-title: "Printable templates for modern life"`
- `category 1: "Wedding Printables"`

If you like your changes:

- click `Export State`
- click `Export HTML`

## Step 3: Add products later

When you are ready, we can replace placeholder cards with real products.

For each product, we usually need:

- product title
- short description
- price
- cover image
- product slug or website route

## Step 4: Sell products on the website

The stronger setup now is:

- website for branding and catalog
- website cart and checkout
- website account and download delivery

That means:

1. customer visits your website
2. clicks into a website product page
3. adds the product to cart
4. pays through website checkout
5. unlocks the download in their account

## Step 5: Publish online

Use one of these free options:

- Netlify
- Vercel

Files already included:

- `netlify.toml`
- `vercel.json`
- `DEPLOY.md`

## Step 6: Rebuild exported website files

If you export a project package from the browser helper:

- `the-digital-atlas-project-package.json`

You can rebuild real edited website files using:

- `Rebuild-WebsitePackage.bat`

That creates:

- `exported-site`

## Best beginner workflow

1. Open `index.html`
2. Edit with AI Helper
3. Export state or package
4. Rebuild files if needed
5. Add products
6. Publish to Netlify
