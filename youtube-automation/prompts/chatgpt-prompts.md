# ChatGPT Prompt Pack

## Channel Idea Prompt

```text
Act as a YouTube strategist for a faceless AI-tools channel targeting students, creators, and freelancers in India. Give me 30 video ideas with high click potential. Split them into long videos and Shorts. Keep them beginner-friendly, practical, and monetizable.
```

## Title Prompt

```text
Give me 15 high-CTR YouTube titles for this topic: [TOPIC].
Rules:
- simple English
- curiosity without clickbait lies
- under 65 characters
- suitable for a faceless channel
```

## Long Video Script Prompt

```text
Write a faceless YouTube script for a 6 to 8 minute video on: [TOPIC].
Audience: beginners in India.
Style: simple English, short sentences, useful and energetic.
Structure:
1. hook in first 15 seconds
2. problem
3. step-by-step explanation
4. examples
5. quick recap
6. soft call to action
Do not make it generic. Make it feel original and practical.
```

## Shorts Script Prompt

```text
Write 10 YouTube Shorts scripts on: [TOPIC].
Rules:
- 20 to 30 seconds each
- strong hook in first line
- one idea per Short
- simple words
- end with a tiny follow CTA
```

## Description Prompt

```text
Write a YouTube description for this video: [TITLE].
Include:
- a short summary
- naturally written keywords
- a call to action
- placeholders for affiliate links
Keep it clean and not spammy.
```

## Thumbnail Prompt

```text
Give me 10 thumbnail text options for this YouTube video: [TITLE].
Rules:
- 2 to 5 words
- bold and emotional
- easy to read on mobile
```

## Hook Rewrite Prompt

```text
Rewrite this YouTube intro to make the first 10 seconds stronger and more curiosity-driven without sounding fake:
[PASTE INTRO]
```

## SEO Tags Prompt

```text
Generate 20 YouTube SEO tag ideas for this topic: [TOPIC].
Prioritize beginner search intent and Indian audience relevance.
```

## Repurposing Prompt

```text
Turn this long-video script into:
1. 3 YouTube Shorts
2. 1 community post
3. 1 pinned comment
[PASTE SCRIPT]
```
