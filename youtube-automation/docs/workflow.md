# Weekly Workflow

## Monday

- review the content calendar
- select `3` long videos and `5` Shorts
- create project folders using the helper script

## Tuesday

- write all scripts in one batch
- generate title options

## Wednesday

- record screen captures where needed
- collect visuals, icons, and screenshots
- generate AI voice if using narration

## Thursday

- edit `2` long videos
- edit `3` Shorts

## Friday

- finish remaining edits
- make thumbnails
- write descriptions and upload all videos

## Saturday

- schedule next week
- log analytics for recent uploads

## Sunday

- review what worked
- update next week's choices

## Keep It Simple

Use one topic to create:
- `1` long video
- `2-3` Shorts
- `1` community post later

This is how you scale without filming.
