# Manual Upload Checklist

These are the only actions that still need to happen outside this workspace.

## Before Upload

1. Export the finished video from Canva or CapCut.
2. Export or convert the chosen thumbnail image.
3. Copy the final title and description from the relevant video folder.

## In YouTube Studio

1. Click `Create`
2. Click `Upload videos`
3. Select the exported file
4. Paste title
5. Paste description
6. Upload thumbnail
7. Add playlist
8. Set audience
9. Keep checks default unless needed
10. Publish or schedule

## After Publish

1. Add a pinned comment
2. Add affiliate links if available
3. Log the video in `data/analytics-tracker.csv`
